Jak uruchomić Intel NPU w Chrome

Chrome musi udostępnić eksperymentalne API WebNN. Bez niego aplikacja użyje WebGPU albo CPU.

  1. Użyj aktualnego Chrome na Windows 11 i zainstaluj najnowszy sterownik Intel NPU / Intel AI Boost.
  2. Otwórz w nowej karcie:
    chrome://flags/#web-machine-learning-neural-network
  3. Przy opcji Web Machine Learning Neural Network wybierz Enabled.
  4. Kliknij Relaunch, aby całkowicie ponownie uruchomić Chrome.
  5. Wróć na tę stronę, otwórz diagnostykę i sprawdź, czy pojawiło się WebNN: tak.
  6. Wybierz Tylko NPU i kliknij Uruchom silnik. Dopiero komunikat Aktywny backend: NPU potwierdza użycie NPU.
Ważne: sama obecność WebNN nie gwarantuje, że dany model uruchomi się na NPU. Zależy to od sterownika, wersji Chrome i obsługiwanych operatorów modelu.
